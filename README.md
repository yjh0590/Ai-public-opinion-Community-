# 와글

생각 하나에 쏟아지는 서로 다른 반응. 디시인사이드, 에펨코리아, 더쿠, 인스티즈, 네이트판, 블라인드, 에브리타임, 당근 동네생활, 맘카페, X, 스레드의 말투·닉네임 형식·색감을 흉내 낸 AI 반응 시뮬레이터입니다. 사이트 이름은 분위기 참고용 표기이며 각 서비스와 무관한 패러디입니다. 한 번에 한 사이트를 고르면 화면 색과 댓글 형식이 그 사이트 느낌으로 바뀝니다.

## 실행

Node.js 22.9 이상이 필요합니다. 추가 패키지 설치는 필요하지 않습니다.

```powershell
npm.cmd run dev
```

브라우저에서 http://localhost:4173 을 여세요. 포트는 `.env`의 `PORT`로 변경할 수 있습니다.

## 실제 AI 연결

처음에는 **데모 모드**로 실행됩니다. 데모는 주제에 따라 준비된 문장을 조합하며 실제 AI 생성이나 여론 수집을 하지 않습니다.

1. `.env.example`을 `.env`로 복사합니다.
2. `.env`의 `OPENAI_API_KEY`에 본인의 키를 입력합니다. 브라우저에 키를 입력하거나 소스에 커밋하지 마세요.
3. 필요하면 `OPENAI_MODEL`을 변경한 뒤 서버를 다시 시작합니다. 기본 모델은 `gpt-4.1-mini`입니다.
4. 화면에 **AI 연결됨**이 나타나면 실제 AI 요청을 사용할 수 있습니다. 이 표시는 서버의 키 설정 여부를 의미하며 키의 유효성은 첫 생성 요청에서 확인됩니다. API 사용료가 발생할 수 있습니다.

서버는 [OpenAI Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create)의 JSON Schema 구조화 출력을 사용합니다. 생성 실패는 화면에 오류로 표시하며 데모로 몰래 대체하지 않습니다. API 키는 서버에서만 사용합니다. 실제 AI 모드에서 입력한 글은 OpenAI로 전송되고 요청에는 `store: false`를 설정합니다. 이는 모든 제공자 로그의 보관을 비활성화한다는 뜻은 아닙니다.

## 사용 방법

- 사이트 카드 하나를 선택합니다. 다른 카드를 누르면 이전 선택은 풀립니다.
- **내 의견 던지기**에서 글을 쓰거나 예시를 선택합니다.
- **AI 일상 엿보기**에서는 AI에게 한 부탁을 쓰면 그 일을 겪은 AI와 다른 AI들의 이야기가 나옵니다.
- `반응 구경하기` 또는 `Ctrl/⌘ + Enter`로 제출합니다.
- 제출하면 와글 화면을 벗어나 고른 사이트를 흉내 낸 페이지(게시판형·앱형·피드형)로 들어가고, 댓글이 그 사이트 형식으로 차례로 달립니다. `← 와글로` 또는 브라우저 뒤로가기로 돌아옵니다. 공감, 공감순 정렬, 새 반응 생성, 글 복사를 지원합니다.
- **내 이야기**에서 최근 20개 기록을 다시 보거나 삭제할 수 있습니다. 기록은 해당 브라우저의 localStorage에 저장됩니다.

## 검증

```powershell
npm.cmd run check
npm.cmd test
```

테스트는 데모 응답, 모든 사이트, AI 일상, 입력 검증, 요청 제한, 파일 접근 제한, 모의 AI 응답 및 실패 처리를 확인합니다. 실제 유료 API를 호출하지 않습니다.

## 파일 구성

- `public/`: 반응형 화면, 브라우저 동작, 사이트별 말투 정의와 데모 생성기(`community.js`), 사이트별 페이지 렌더링(`sites.js`). 정적 서버로 열어도 데모 체험이 가능합니다.
- `server.mjs`: 정적 파일 서버, `/api/status`, `/api/reactions`, 실제 AI 호출.
- `tests/server.test.mjs`: Node.js 기본 테스트 도구로 실행하는 통합 테스트.

서버는 로컬 사용을 위해 `127.0.0.1`에 바인딩합니다. 실제 AI 서버를 외부 배포하기 전에는 호스팅 환경에 맞는 접근 인증과 사용자별 사용량 제한을 추가하세요. 화면의 Google Fonts를 불러올 수 없어도 시스템 글꼴로 동작합니다.

## oddz 연결 및 정적 배포

공개 데모 주소: https://oddz.click/wagle/ · 프로젝트 소개: https://oddz.click/projects/wagle.html

```powershell
npm.cmd run build:static
```

`dist/`에 공개 자산만 내보냅니다. 정적 배포본은 데모 모드를 명시하며 AI API를 호출하지 않습니다. 경로가 상대 주소라 하위 폴더에서도 동작합니다. oddz 사이트는 `yjh0590/oddz_main`의 GitHub Pages로 배포됩니다. 앱을 수정한 뒤에는 다시 빌드한 `dist/`의 파일들을 해당 저장소의 `wagle/`에 복사하고 커밋·푸시해야 체험판에 반영됩니다. `.env`와 서버 코드는 복사하지 마세요.

모든 댓글과 공감 수는 가상 데이터입니다. 실제 커뮤니티의 의견이나 실제 여론을 대표하지 않습니다.
